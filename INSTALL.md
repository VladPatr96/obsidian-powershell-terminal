# Installation

## Manual (recommended)

1. Download `main.js`, `styles.css`, `manifest.json` from [Releases](../../releases)
2. Create folder `.obsidian/plugins/powershell-terminal/` in your vault
3. Copy all three files into that folder
4. Open Obsidian → Settings → Community Plugins → Enable "PowerShell Terminal"

## Via BRAT

1. Install [BRAT plugin](https://github.com/TfTHacker/obsidian42-brat)
2. BRAT → Add Beta Plugin → enter this repository URL
3. Enable "PowerShell Terminal" in Community Plugins

## Requirements

- Windows 10 or later
- PowerShell 5.1 (`powershell.exe`) or PowerShell 7 (`pwsh.exe`)
- Obsidian 1.4.0+
